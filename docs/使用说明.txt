桌序 DeskOrder 1.0.0 - 使用说明
=====================================

一、这是什么
------------
一个把 Windows 桌面整理干净的桌面增强小工具，绿色便携、无需安装：

· Dock 程序坞    底部放常用软件，桌面图标可以收进 Dock
· 律动条        桌面上一根跟着系统声音跳动的透明频谱条
· 任务栏透明    通透 / 磨砂 / 亚克力三种（能否生效取决于系统）
· 音乐卡片      本地 mp3 / wav / wma 播放 + 播放列表

系统要求：Windows 10 1809 及以上或 Windows 11（x64 / x86），
.NET Framework 4.8（Win10 1903+ 与 Win11 已自带，不需要另外安装）。


二、怎么开始
------------
1. 把压缩包解压到任意文件夹。
   建议不要放在 C:\Program Files 这类需要管理员权限的位置。

2. 双击「桌序.exe」即可运行（文件名显示为乱码时，双击 DeskOrder.exe 效果完全相同）。

3. 首次运行会把桌面上已有的快捷方式「固定」到 Dock，方便立刻看到效果。
   注意：只是固定，不会移动或删除你的任何文件。

4. 如果 Windows 弹出蓝色提示「Windows 已保护你的电脑」：
   点「更多信息」→「仍要运行」。
   原因是这个 exe 没有购买代码签名证书，属于未签名程序的常规提示，不是病毒。
   部分安全软件也可能启发式报警，可用包内 SHA256.txt 校验文件是否被改动。

5. 右下角托盘区（可能要点 ^ 展开）会出现桌序图标：
   显示/隐藏 Dock、音乐卡片、设置、退出。


三、常用操作
------------
· Dock 图标左键 = 启动；右键 = 打开 / 在文件夹中显示 / 更换图标 /
  左移 / 右移 / 从 Dock 移除
· Dock 空白处右键 = 添加文件… / 添加文件夹… / 按名称整理 / 打开 Dock 整理
· 把 exe、快捷方式、文件、文件夹直接拖到 Dock 上也能固定；
  Dock 内部拖拽图标可以排序，Dock 上的改动会立即保存
· 主界面「Dock 整理」页：
    - 从桌面整理：勾选桌面快捷方式收进 Dock（桌面图标消失，但随时可以还原）
    - Dock 项目：每行的 ↑ ↓ × 用来调整顺序和移除，右上角可添加文件/文件夹
· 主界面「音乐与律动」页：打开本地音乐、调「律动条距 Dock」的像素、
  设置全屏时是否自动隐藏律动条
· 快捷键：Ctrl + Alt + D 显示/隐藏 Dock；Ctrl + Alt + M 显示/隐藏音乐卡片
· 退出：托盘图标右键 → 退出桌序（关闭主窗口默认最小化到托盘，Dock 继续工作）


四、开机启动（可选）
--------------------
主界面「设置」页最上面的「开机启动桌序」开关，打开后登录 Windows 就
自动以 Dock + 托盘方式启动。程序会按顺序尝试三种登记方式，成功一个就停：

  1. 当前用户注册表 Run 项（任务管理器 →「启动应用」里能看到）
  2. 当前用户「启动」文件夹里的快捷方式
  3. 登录计划任务（任务计划程序里能看到 DeskOrder）

· 关闭开关会把三种登记项都清掉。
· 挪动/重命名程序文件夹后，下一次启动会自动把登记项里的路径改成新位置。
· 如果开关打不开、或者提示「已被 Windows『启动应用』关闭」：
     - 先看开关下面那行状态文字，它会写明失败在哪一层、为什么；
     - 点「重新登记」通常就能修好（例如被系统「启动应用」开关关掉时）；
     - 若当前是受限环境（沙箱、低完整性会话、公司策略），注册表和用户
       目录都不允许写，此时点「复制启动命令」，把复制到的那一行
       PowerShell 命令粘到普通 PowerShell 窗口里执行一次即可；
     - 也可以用命令查看状态：桌序.exe --startup status
       （会打印 enabled / mechanism / stale / osDisabled / runKeyWritable /
        integrity / problem，以及可直接粘贴的 manualCommand）
· 登记到 Run 项后，想彻底清除：关掉这个开关，或删掉注册表
  HKCU\Software\Microsoft\Windows\CurrentVersion\Run 下的 DeskOrder 值。


五、数据放在哪里 / 怎么卸载
---------------------------
本版本是便携模式：所有数据都在程序旁边的 DeskOrderData 文件夹里——

  DeskOrderData\settings.json          设置
  DeskOrderData\pins.json              Dock 固定项
  DeskOrderData\playlist.json          播放列表
  DeskOrderData\DockItems\             被收进 Dock 的快捷方式（原文件，未删除）
  DeskOrderData\logs\                  日志

· 想改回放用户目录（%APPDATA%\DeskOrder）：删掉 portable.txt 即可。
· 卸载：托盘 → 退出，然后删除整个文件夹。不留注册表垃圾。
  唯一例外：如果你在设置里开启过「开机启动」，它会写
  HKCU\Software\Microsoft\Windows\CurrentVersion\Run 下的一个 DeskOrder 值，
  在设置里关掉即可清除。


六、隐私
--------
· 不联网、不上传、不统计，没有任何网络功能。
· 音频只做系统回环（loopback）频谱计算：不录音、不保存音频、不使用麦克风。
· 只有你主动开启「纯净桌面」才会改动桌面图标显示，退出桌序时自动恢复。


七、常见问题
------------
Q: 双击没反应 / 打不开？
   A: 打开 DeskOrderData\logs\app.log 看最后几行；如果日志里写着
      「配置目录不可写」，说明程序放在了只读位置，换一个文件夹即可。
      也可能是被安全软件拦截，加白名单后再运行。

Q: 任务栏没有变透明？
   A: Windows 11 24H2 之后的 XAML 任务栏经常直接拒绝第三方透明，这是系统限制。
      可以改用「沉浸模式：自动隐藏任务栏」，或关掉这项功能。先用「预览 8 秒」试。

Q: Dock 不见了？
   A: 按 Ctrl + Alt + D，或托盘图标 → 显示/隐藏 Dock。
      开了「自动隐藏」时，鼠标移到屏幕底部会自动出现。

Q: 律动条不跳？
   A: 确认「音乐与律动 → 桌面透明律动条」是开着的；频谱跟随系统声音，
      随便放一首歌就会动。觉得离 Dock 太远/太近，拖「律动条距 Dock」滑条。

Q: 为什么 QQ / 浏览器能打开，个别软件不行？
   A: 桌序用系统的 ShellExecute 打开快捷方式，参数、工作目录、UWP/AppID 都会保留。
      如果某个软件仍然打不开，把 DeskOrderData\logs\app.log 发给作者看即可。

Q: 两个桌序图标 / 开了两次？
   A: 同时只会运行一个实例，第二次启动会把已有窗口调到前面。

Q: 开机启动的开关点了没反应 / 提示无法修改？
   A: 说明当前进程不允许写注册表（受限令牌、沙箱或低完整性会话）。
      看开关下面的状态文字，它会写明卡在哪一层；点「重新登记」重试，
      或点「复制启动命令」把那一行粘到普通 PowerShell 窗口执行一次。
      命令行的等价检查：桌序.exe --startup status

Q: 重启后没有自动启动？
   A: 运行 桌序.exe --startup status，重点看：
        osDisabled = true  → 被 Windows「启动应用」关掉了，点「重新登记」恢复；
        stale = true       → 登记的还是旧路径，点「重新登记」改成当前路径；
        enabled = false    → 三种登记方式都没成功，按上面那个问题处理。


八、包内文件
------------

  portable.txt        便携模式标记，删掉就改用 %APPDATA%\DeskOrder
  使用说明.txt        本文件
  README.md           完整功能与设计说明（给想看细节的人）
  SHA256.txt          文件校验值
